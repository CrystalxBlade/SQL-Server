# Advanced SQL

This folder is for concepts you can study after the fundamentals.

## Temporary tables
Tables created for temporary work during a session or procedure.

## Table variables
Variables that can hold table-shaped data and are useful for smaller intermediate results.

## Recursive CTEs
CTEs that refer to themselves, useful for hierarchical data such as organizational structures.

## Dynamic SQL
SQL statements constructed and executed at runtime.

## TRY...CATCH
SQL Server's error-handling mechanism for handling runtime errors.

## Isolation levels
Control how transactions interact with data changes made by other transactions.

## Execution plans
Show how SQL Server intends to execute a query and can help diagnose performance problems.

## Query optimization
The process of making queries perform efficiently by improving queries, indexes, schema design, and other factors.
