# Introduction to MS SQL Server

## What is SQL?
SQL (Structured Query Language) is used to communicate with relational databases.

## What is Microsoft SQL Server?
Microsoft SQL Server is a relational database management system (RDBMS) developed by Microsoft.

## Key ideas
- Server / instance
- Database
- Table
- Row
- Column
- Primary key
- Foreign key

## Example
```sql
SELECT name
FROM sys.databases;
```
